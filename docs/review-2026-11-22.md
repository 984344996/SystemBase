## 已核实无问题

- token 刷新：同标签页并发 401 只刷新一次，跨标签页用 Web Locks 串行
- 登出清理动态路由；`redirect` 只接受站内路径；全项目无 `v-html`
- 改密 / 重置密码 / 禁用 / 删除用户后旧 token 立即失效；refresh 轮换并发安全
- 生产 500 不返回 stack；删角色、删菜单有引用检查；多步写都在事务内
- 文件存储路径由服务端生成（无穿越），下载鉴权 + nosniff，扩展名 + 魔数双重校验
- 操作审计对 password / token / captcha 脱敏；main.ts 有 shutdown hooks、body 限制、CORS 白名单
- 前端无 sourcemap，`import.meta.env` 无敏感值；轮询与监听都有清理
